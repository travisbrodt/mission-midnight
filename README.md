# Mission Midnight

A content-only MVP website for Mission Midnight — a personal studio for exploration, creation, and disciplined work.

## What this is

Static, minimal presence: a homepage with studio copy and a stub “Why Midnight” page. No CMS, tracking, or scripts. Typography-first, black/white/neutral, system fonts only.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. **Settings → Pages** → Source: **Deploy from a branch**.
3. Branch: `main` (or your default), folder: **/ (root)**.
4. Save. The site will be at `https://<username>.github.io/<repo>/`.

If the repo is named `mission-midnight`, use that in the URL. For a user/org site, use a repo named `<username>.github.io` and the site will be at `https://<username>.github.io/`.

## Extending later

- Add pages by creating new `.html` files and linking them from the nav in `index.html` and `why-midnight.html`.
- Keep one shared `styles.css`; add section-specific classes as needed.
- To add a font or script, do it sparingly and document the reason.
